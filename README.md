# Brainstorming & prototyping — separation system (Dhia)

**Dhia**'s idea for a crate **separation system**: the `mjarfa` mechanism driven by a screw-and-nut, belt tensioner, levers and a slot-and-roller guide.

## Contents
- `Assem3.SLDASM`, base separation, small lever, stem supports — main assembly and parts
- `mjarfa dhia ( vis ecrou )/` — screw-and-nut `mjarfa` version
- `gripper/` — gripper parts
- `slot and galet/` — slot and roller guide
- `caster ball + support/` — caster ball
- `assembly mdf/` — laser-cut (MDF) assembly
- `impression/` — print-ready files
- `piece util/` — reusable parts
